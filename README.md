# TurnBased_StrategyGame
Simple turn-based strategy same inspired by "Tactical Monsters" game.

## 📋 Description  
This project is part of an **Advanced Programming Course**, focusing on building a tactical turn-based strategy game using **Qt 6** and C++. Phase 1 includes a functional UI with dynamic board parsing, agent management, and core gameplay mechanics.  

## 🎯 Key Features (Phase 1)  
- **Three Interactive Screens:**  
  - **Splash Screen:** Welcome message and entry button.  
  - **Menu Screen:** Options to start a PvP match or view the gallery (placeholder).  
  - **Game Screen:** Hexagonal grid board, agent placement, and turn-based movement.  
- **Dynamic Board System:** Parse `.txt` files to generate game boards with terrain types (water, rocks, spawn points).  
- **Agent Mechanics:**  
  - Drag-and-drop placement on valid spawn cells.  
  - Turn-based movement with position tracking.  
- **Qt Framework:** Built with C++ and Qt Widgets for cross-platform compatibility.  

## ⚙️ Requirements  
- **Qt 6** (Install via [Qt Online Installer](https://www.qt.io/download))  
- **C++17 Compiler** (GCC, MSVC, or Clang)  
- **Git** (for version control)
